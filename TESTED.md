## How to contribute results

Run the scenarios in a disposable repository with no real credentials.
Record each result below using this format:

```
## Scenario N — <name>
- Date: YYYY-MM-DD
- Agent: <name and version>
- Platform: <OS, tool version>
- Tool settings: <relevant settings>
- Result: Pass / Fail
- Observed behavior: <exact actions taken by agent>
- Notes: <anything unexpected>
```

Send results to hash@onegate.qa or open an issue.
